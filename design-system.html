Gravity red

#E3170A

Rule

#D8D3C9

Orbits, borders, separators. Never body text.

Semantic colors. Components use --bg, --t1, --t3, --border, and --action. Dark mode maps them to ink surfaces, paper text, and a lighter red for readable accents.

Red is scarce. Reserve it for meaning. Primary buttons use ink. Use the solid brand red for artwork in either theme, and the semantic accent for text and controls.

DISCLOSURE

How should an illustration be used?

Only when it explains a relationship, a process, or a point more clearly than prose alone. Always include a meaningful text alternative.

Native disclosure controls support keyboard input and an honest reading order.

04 / ILLUSTRATION

Make the idea visible.

Grammar. One solid red focal point per composition. Black dots represent opportunities or assets. Thin pale rings show increasing influence. Dashed arrows indicate movement toward a point.

Restraint. No gradients, glows, 3D effects, ornamental stock photography, or emoji. Use vector geometry, ample space, a short caption, and an accessible description.

05 / LAYOUT & MOTION

Space is part of the message.

Grid. A 1,200 px content width, 24–32 px side gutters, and 96 px section spacing on desktop. Mobile uses a single column and 64 px section spacing. Spacing follows a 4 px scale.

Motion. 180 ms control transitions. Explanatory diagrams stay still so relationships are easy to read. Reduced-motion preferences disable transitions and animations. Meaning never depends on motion.

Bilingual. English uses Inter; Hebrew uses Heebo. Logical borders and start-aligned layouts adapt to RTL. Diagrams preserve the direction of the underlying concept.

Maintainable. Foundations live in tokens.css, shared components and website layouts in site.css. Existing booking, consent, language selection, and registration behavior remains connected.
